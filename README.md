### Project 03

# Product Management Dashboard

A responsive Product Management Dashboard built using HTML, CSS, and JavaScript. Users can create, update, delete, search, and view product details through a clean and modern interface. Product data is stored in Local Storage, allowing information to persist even after page refreshes.

## 🚀 Features

- Create New Products
- Update Existing Products
- Delete Products with Confirmation Popup
- Search Products by Name
- View Detailed Product Information
- Category Selection Dropdown
- Product Category Icons/Images
- Local Storage Data Persistence
- Responsive and Modern UI

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- Local Storage API

CashPilot is a simple and responsive Personal Finance Tracker built using HTML, CSS, JavaScript, and Chart.js. It helps users manage their income and expenses, view financial summaries, and analyze spending with interactive charts.

## 🚀 Features

- 🔐 User Registration & Login
- 👤 Profile Picture Support
- 💵 Add Income & Expense Transactions
- 📊 Dashboard with Financial Summary
- 📈 Bar Chart for Income vs Expense
- 📉 Line Chart for Expense Analysis
- 🌙 Dark / Light Theme Toggle
- 💾 LocalStorage Data Persistence
- 🔄 Reset Transaction Data
- 📱 Responsive UI

## 🛠️ Technologies Used

- CSS3
- JavaScript (ES6)
- Chart.js
- Remix Icons
- LocalStorage API

## Project 05

# 🚀 FocusHub - Productivity Dashboard

> A modern productivity dashboard built using **HTML, CSS, and JavaScript**.  
> FocusHub helps users stay organized, manage daily tasks, track goals, use the Pomodoro technique, and stay motivated—all in one place.

---

## ✨ Features

### 📝 Todo List
- Add new tasks
- Delete completed tasks
- Data is saved using LocalStorage
- Success and warning toast notifications

---

### 📅 Daily Planner
- Plan your daily schedule
- Time displayed in **12-hour format (AM/PM)**
- Planner data stored in LocalStorage

---

### 🍅 Pomodoro Timer
- Focus Timer
- Short Break Timer
- Long Break Timer
- Custom timer settings
- Timer settings saved in LocalStorage

---

### 🌤 Weather
- Live weather information using Weather API
- Displays current temperature
- Clean and responsive weather card

---

### 🎯 Daily Goals
- Add and manage daily goals
- Track daily progress
- Data saved automatically

---

### 💬 Motivation Quotes
- Generate random motivational quotes
- Stay motivated while working

---

### 🕒 Live Clock
- Live digital clock
- Dynamic greeting:
  - 🌅 Good Morning
  - ☀️ Good Afternoon
  - 🌇 Good Evening
  - 🌙 Good Night
- Current Day
- Current Date

---

### 🌙 Dark / Light Theme
- Switch between Dark and Light mode
- Theme preference saved using LocalStorage

---

### 🔔 Toast Notifications
Beautiful animated notifications for:

- Todo Added
- Planner Saved
- Goal Added
- Task Deleted
- Data Reset
- Settings Updated

---

### ⚠ Custom Confirmation Popup
Instead of using the browser's default confirmation box, this project includes custom confirmation modals for:

- Delete Task
- Delete Planner
- Reset All Data

---

### 💾 LocalStorage
User data is stored locally, including:

- Todos
- Planner
- Daily Goals
- Theme
- Pomodoro Settings

No database is required.

---

## 🛠 Technologies Used

- HTML5
- CSS3
- JavaScript (ES6)
- LocalStorage
- Weather API
- Font Awesome

---

## 📱 Responsive Design

FocusHub is fully responsive and works smoothly on:

- 💻 Desktop
- 📱 Mobile
- 📟 Tablet
